# MP3-site

Plak een TikTok- of YouTube-link op je iPhone en bewaar de mp3 in de app Bestanden.

- Draait op de pc van de eigenaar (yt-dlp + ffmpeg); GitHub bewaart alleen de code.
- Starten: `python tools/mp3-site/server.py`, daarna op de iPhone (zelfde wifi): `http://<pc-ip>:8780`
- Alleen links van youtube.com, youtu.be en tiktok.com. Bestanden blijven 1 uur op de pc.
- Alleen voor eigen video's of muziek die je mag gebruiken.
