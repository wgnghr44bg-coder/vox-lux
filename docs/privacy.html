Privacy policy – Vox Lux Uploader

The Vox Lux Uploader is a private tool used only by the owner of the Vox Lux YouTube channel to upload their own videos to their own channel.

  • It uses the YouTube Data API with the youtube.upload permission, only to upload videos and set their title, description, tags and thumbnail.
  • It does not collect, store, sell or share personal data of anyone else.
  • Access tokens are kept only in the owner's private environment and are never published.
  • The owner can remove access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy.
