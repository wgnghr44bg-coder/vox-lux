# Bronnen video 6: werkt AI eigenlijk? (gelezen 20 nov 2026)

Harvard-onderzoek (zelf gelezen, PDF fion.ac/jellyfish.pdf, versie 19 nov 2026, eerste versie 7 jan 2026):
- "Artificial Intelligence in the Firm: Bottlenecks in Software Production", Fiona Chen en James Stratton (Harvard University; job market paper, niet peer-reviewed).
- Data van Jellyfish (analyseplatform voor software-teams): 445 mln werkgebeurtenissen, 720.542 werknemers, 655 bedrijven, jan 2021 - aug 2026. GitHub, Jira, Google Calendar, AI-gebruik (GitHub Copilot, Cursor, Claude Code).
- Methode: verschil in moment waarop bedrijven AI invoerden.
- Assistenten, 12 maanden na invoering: +30,4% regels code, +16,8% commits, +20,9% pull requests. Agents bovenop: +44,0% regels code, +36,0% commits, +35,7% pull requests.
- Afgemaakt werk (Jira-issues opgelost = code in productie): assistenten -1,5%, agents +13,7% (grensgeval significant); grote projecten (epics) assistenten +3,4%, agents +18,0%. Issues werden niet groter.
- Werkgelegenheid: geen significant effect (assistenten +3,0%, agents -2,6%).
- Programmeurs besteden 30-40% van hun tijd aan code schrijven.
- Flessenhals code review: tijd van indienen tot samenvoegen +56,1% na agents; wachttijd +59,9%; actieve review +58,5%; aandeel met commentaar +13,1%; aantal commentaren per wijziging +38,6%.
- Reviewers kijken meestal code na die ze kennen (82,8%). 79,1% van de bedrijven heeft AI-reviewtools, maar mensen schrijven nog verreweg de meeste reviews.
- Interview (citaat): "People could make a huge number of commits quickly, but code review was still the bottleneck." ... "After some outages that were caused by AI-generated commits, there were also new rules requiring senior engineer approval for AI-generated code".
- Model: AI-agents maken code schrijven 73,7% productiever; lange termijn: meer output en minder banen, kleiner effect als de review-flessenhals blijft.
- Paper: "the frontier AI labs state that AI is already writing 80% of their code".

Stiglitz (Hindustan Times Leadership Summit, New Delhi, 14 nov 2026; via Mint/MENAFN, Inshorts):

- Vraagprobleem: als AI banen vernietigt, wie heeft dan het inkomen om te kopen wat AI maakt.
